Weak Law of Large Numbers & Central Limit Theorem

1. Sample Mean

Given i.i.d. X₁, X₂, …, Xₙ with E[Xᵢ] = μ and Var(Xᵢ) = σ²:

X̄ₙ = (1/n) Σ Xᵢ    E[X̄ₙ] = μ    Var(X̄ₙ) = σ²/n

2. Weak Law of Large Numbers (WLLN)

X̄ₙ →ᵖ μ   as n → ∞

Meaning: As sample size grows, the sample mean converges to the true population mean.

Proof sketch: By Chebyshev: P(|X̄ₙ − μ| ≥ ε) ≤ σ²/(nε²) → 0

ML relevance: Justifies using sample averages to estimate population parameters. Foundation of Monte Carlo methods.

3. Central Limit Theorem (CLT)

(X̄ₙ − μ) / (σ/√n) →ᵈ N(0,1)   as n → ∞

Equivalently: X̄ₙ ≈ N(μ, σ²/n) for large n

Key insight: Regardless of the original distribution of Xᵢ, the sample mean is approximately Normal for large n.

Example: Xᵢ ~ Uniform(0,1), μ=0.5, σ²=1/12.
For n=100: X̄ₙ ≈ N(0.5, 1/1200).
P(X̄ₙ > 0.55) ≈ P(Z > (0.55−0.5)/√(1/1200)) = P(Z > 1.73) ≈ 0.042

4. Sum Version of CLT

Sₙ = Σ Xᵢ ≈ N(nμ, nσ²)   for large n

Standardize: (Sₙ − nμ)/(σ√n) → N(0,1)

5. When to Use CLT

  • n ≥ 30 is a common rule of thumb (if distribution isn't too skewed)
  • Approximate P(a < X̄ₙ < b) using Normal distribution
  • Approximate binomial with Normal: Bin(n,p) ≈ N(np, np(1−p)) when np and n(1−p) ≥ 5

6. Exam Checklist

  • State WLLN and CLT precisely
  • Standardize and use Z-tables
  • Approximate binomial probabilities via Normal
  • Find required n for a given accuracy on X̄ₙ
