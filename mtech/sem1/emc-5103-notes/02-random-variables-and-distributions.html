Random Variables, PMF, PDF, Expectation & Variance

1. What is a Random Variable?

A random variable (RV) X is a function X: Ω → ℝ that assigns a number to each outcome.

  • Discrete RV: Takes countable values (e.g., die roll: 1,2,3,4,5,6)
  • Continuous RV: Takes uncountable values (e.g., height, time, temperature)

3. PDF — Probability Density Function (Continuous)

f(x) ≥ 0,   ∫₋∞^∞ f(x) dx = 1
P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx

Note: P(X = x) = 0 for any single point in continuous case!

4. CDF — Cumulative Distribution Function

F(x) = P(X ≤ x)
  • Non-decreasing, right-continuous
  • lim F(x) = 0 as x→−∞; lim F(x) = 1 as x→+∞
  • Discrete: F(x) = Σ p(k) for k ≤ x
  • Continuous: F(x) = ∫₋∞ˣ f(t) dt,   f(x) = dF/dx

5. Expectation (Mean)

E[X] = Σ x·p(x)   [discrete]    E[X] = ∫ x·f(x) dx   [continuous]
E[g(X)] = Σ g(x)p(x)   or   ∫ g(x)f(x)dx

Linearity: E[aX + b] = aE[X] + b  |  E[X + Y] = E[X] + E[Y] (always, even if dependent)

6. Variance & Moments

Var(X) = E[(X − μ)²] = E[X²] − (E[X])²
SD(X) = √Var(X)

k-th moment: E[Xᵏ]  |  Central k-th moment: E[(X−μ)ᵏ]

Var(aX + b) = a²Var(X). For independent X,Y: Var(X+Y) = Var(X) + Var(Y)

7. Exam Checklist

  • Identify distribution type and write PMF/PDF
  • Compute E[X], Var(X) from definition or table
  • Use CDF to find P(a < X < b)
  • Recognize Binomial, Poisson, Normal problems from word statements
  • Standardize Normal: Z = (X−μ)/σ
