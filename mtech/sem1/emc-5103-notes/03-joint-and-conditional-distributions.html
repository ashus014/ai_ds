Joint, Marginal & Conditional Distributions

1. Joint Distribution

For two RVs X and Y:

Discrete: p(x,y) = P(X=x, Y=y)    Continuous: f(x,y) with ∫∫ f(x,y) dx dy = 1

2. Marginal Distributions

"Sum out" the other variable:

p_X(x) = Σᵧ p(x,y)   [discrete]    f_X(x) = ∫ f(x,y) dy   [continuous]

3. Conditional Distribution

p_{Y|X}(y|x) = p(x,y) / p_X(x)    for p_X(x) > 0
f_{Y|X}(y|x) = f(x,y) / f_X(x)

Conditional expectation: E[Y|X=x] = Σ y·p(y|x) or ∫ y·f(y|x) dy

4. Independence of Random Variables

X and Y independent ⟺ p(x,y) = p_X(x)·p_Y(y)   for all x,y

If independent: E[XY] = E[X]E[Y] and Var(X+Y) = Var(X) + Var(Y)

5. Covariance & Correlation

Cov(X,Y) = E[(X−μₓ)(Y−μᵧ)] = E[XY] − E[X]E[Y]
ρ(X,Y) = Cov(X,Y) / (σₓ · σᵧ)    where −1 ≤ ρ ≤ 1
  • ρ = 1: perfect positive linear relationship
  • ρ = −1: perfect negative linear relationship
  • ρ = 0: uncorrelated (not necessarily independent!)
Var(X + Y) = Var(X) + Var(Y) + 2·Cov(X,Y)

6. Functions of Random Variables

Discrete: If Y = g(X), then p_Y(y) = Σ p(xᵢ) where g(xᵢ) = y

Continuous — CDF method: F_Y(y) = P(g(X) ≤ y) = P(X ∈ {x : g(x) ≤ y})

Transformation: If Y = aX + b, then f_Y(y) = (1/|a|) f_X((y−b)/a)

7. Exam Checklist

  • Find marginal from joint PMF/PDF
  • Compute conditional distribution and E[Y|X]
  • Check independence via p(x,y) = p_X(x)p_Y(y)
  • Calculate Cov(X,Y) and correlation ρ
  • Find distribution of Y = g(X)
