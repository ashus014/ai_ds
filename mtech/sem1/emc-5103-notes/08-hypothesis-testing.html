Hypothesis Testing & Neyman-Pearson Lemma

1. Framework

  • H₀ (Null hypothesis): status quo, no effect (e.g., μ = μ₀)
  • H₁ (Alternative): what we want to detect (e.g., μ ≠ μ₀)
  • Test statistic: computed from data (e.g., Z = (X̄−μ₀)/(σ/√n))
  • Rejection region: values of test statistic that lead to rejecting H₀

2. Types of Errors

H₀ TrueH₀ False
Fail to reject H₀✓ CorrectType II Error (β)
Reject H₀Type I Error (α)✓ Correct (Power = 1−β)
  • Level of significance α: P(Type I error) = P(reject H₀ | H₀ true)
  • Power: P(reject H₀ | H₁ true) = 1 − β

3. p-value

Probability of observing a test statistic at least as extreme as the one computed, assuming H₀ is true.

Reject H₀ if p-value < α
  • Two-tailed: p = 2·P(Z > |z_obs|)
  • One-tailed right: p = P(Z > z_obs)
  • One-tailed left: p = P(Z < z_obs)

4. Common Tests

TestStatisticWhen to use
Z-test (mean)Z = (X̄−μ₀)/(σ/√n)σ known, large n
t-test (mean)t = (X̄−μ₀)/(S/√n)σ unknown
Z-test (proportion)Z = (p̂−p₀)/√(p₀(1−p₀)/n)Large n
χ² testχ² = Σ(O−E)²/EGoodness of fit

5. Neyman-Pearson Lemma

For testing H₀: θ = θ₀ vs H₁: θ = θ₁, the most powerful test at level α rejects H₀ when:

L(θ₁) / L(θ₀) > k

where k is chosen so P(reject H₀ | H₀) = α.

Meaning: Reject H₀ when the likelihood ratio favors H₁ sufficiently. This gives the Likelihood Ratio Test (LRT).

λ = L(θ₀) / L(θ̂_MLE)    Reject H₀ if λ < k

6. Testing Procedure (Step by Step)

  1. State H₀ and H₁
  2. Choose significance level α
  3. Select appropriate test statistic
  4. Compute observed test statistic from data
  5. Find p-value or critical value
  6. Make decision: reject or fail to reject H₀
  7. State conclusion in context

7. Exam Checklist

  • Set up H₀ and H₁ (one-tailed vs two-tailed)
  • Compute Z or t statistic
  • Find p-value and compare to α
  • Identify Type I and Type II errors in context
  • State Neyman-Pearson lemma and likelihood ratio test
  • Relate to confidence intervals
