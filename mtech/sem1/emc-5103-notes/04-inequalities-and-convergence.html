Markov, Chebyshev & Convergence

1. Markov's Inequality

For non-negative RV X and a > 0:

P(X ≥ a) ≤ E[X] / a

Gives an upper bound on tail probability using only the mean. Loose but requires minimal assumptions.

If E[X] = 10, then P(X ≥ 50) ≤ 10/50 = 0.2

2. Chebyshev's Inequality

For any RV X with mean μ and variance σ², and k > 0:

P(|X − μ| ≥ kσ) ≤ 1/k²

Equivalently: P(|X − μ| < kσ) ≥ 1 − 1/k²

At least 75% of values lie within 2σ of μ (k=2 → 1−1/4 = 0.75)
Chebyshev follows from Markov applied to (X−μ)². Used to prove WLLN.

3. Modes of Convergence

Convergence in Probability

Xₙ →ᵖ X   if   P(|Xₙ − X| > ε) → 0 for all ε > 0

Used in Weak Law of Large Numbers.

Convergence in Distribution (Weak Convergence)

Xₙ →ᵈ X   if   Fₙ(x) → F(x) at continuity points of F

Used in Central Limit Theorem. Weaker than convergence in probability.

Almost Sure Convergence

Xₙ →ᵃ·ˢ· X   if   P(lim Xₙ = X) = 1

Strongest mode. Implies convergence in probability.

Hierarchy: a.s. ⟹ in probability ⟹ in distribution

4. Exam Checklist

  • Apply Markov's inequality to bound tail probabilities
  • Apply Chebyshev to find minimum % within k standard deviations
  • Distinguish between convergence in probability vs distribution
  • State conditions for each type of convergence
