Point Estimation — MLE, MVUE, Rao-Cramér

1. What is an Estimator?

A statistic θ̂ = g(X₁,…,Xₙ) used to estimate unknown parameter θ.

  • Point estimate: single value (e.g., X̄ₙ estimates μ)
  • Estimator vs estimate: θ̂ is the rule; θ̂ = 3.2 is the computed value

2. Properties of Estimators

Unbiasedness

E[θ̂] = θ   for all θ

Example: X̄ₙ is unbiased for μ. Sample variance S² = Σ(Xᵢ−X̄)²/(n−1) is unbiased for σ².

Mean Squared Error (MSE)

MSE(θ̂) = E[(θ̂ − θ)²] = Var(θ̂) + [Bias(θ̂)]²

Efficiency

Among unbiased estimators, the one with smallest variance is most efficient.

Consistency

θ̂ₙ →ᵖ θ   as n → ∞

3. MVUE — Minimum Variance Unbiased Estimator

The unbiased estimator with the smallest possible variance.

If θ̂ is a sufficient statistic and unbiased, it is MVUE (by Lehmann-Scheffé theorem).

4. Rao-Cramér (Cramér-Rao) Lower Bound

For unbiased θ̂ under regularity conditions:

Var(θ̂) ≥ 1 / I(θ)

where I(θ) = Fisher Information:

I(θ) = E[(∂/∂θ log L(θ))²] = −E[∂²/∂θ² log L(θ)]

An estimator achieving this bound is efficient. MLE often achieves it asymptotically.

5. Maximum Likelihood Estimation (MLE)

Choose θ that maximizes the likelihood of observed data:

L(θ) = Π f(xᵢ; θ)    θ̂_MLE = argmax L(θ) = argmax log L(θ)
DistributionParameterMLE
Bernoulli(p)pp̂ = (Σxᵢ)/n = sample proportion
Normal(μ, σ²)μμ̂ = X̄ₙ
Normal(μ, σ²)σ²σ̂² = Σ(Xᵢ−X̄)²/n
Poisson(λ)λλ̂ = X̄ₙ
Exponential(λ)λλ̂ = 1/X̄ₙ

Invariance property: If θ̂ is MLE of θ, then g(θ̂) is MLE of g(θ).

ML relevance: MLE is how neural network weights are trained (maximize likelihood of data under the model).

6. MLE Procedure

  1. Write likelihood L(θ) = Π f(xᵢ; θ)
  2. Take log: ℓ(θ) = Σ log f(xᵢ; θ)
  3. Differentiate: dℓ/dθ = 0
  4. Solve for θ̂
  5. Verify it's a maximum (second derivative < 0)

7. Exam Checklist

  • Check if estimator is unbiased
  • Compute MSE = Variance + Bias²
  • Derive MLE for common distributions
  • State Rao-Cramér bound and check efficiency
