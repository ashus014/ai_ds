Conditional Probability, Bayes' Rule & Independence

1. Sample Space & Basic Probability

A sample space Ω is the set of all possible outcomes. An event A ⊆ Ω.

P(A) = (Number of favorable outcomes) / (Total outcomes)   [equally likely case]

Axioms of probability:

  • P(A) ≥ 0 for any event A
  • P(Ω) = 1
  • For mutually exclusive events A₁, A₂, …: P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + …
Key identity: P(Aᶜ) = 1 − P(A)  |  P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

2. Conditional Probability

Probability of A given B has occurred — we restrict the sample space to B.

P(A | B) = P(A ∩ B) / P(B)    provided P(B) > 0

Intuition: Out of all outcomes where B happened, what fraction also satisfies A?

Multiplication Rule

P(A ∩ B) = P(B) · P(A | B) = P(A) · P(B | A)

For n events: P(A₁ ∩ A₂ ∩ … ∩ Aₙ) = P(A₁)·P(A₂|A₁)·P(A₃|A₁∩A₂)…

3. Law of Total Probability

If B₁, B₂, …, Bₙ partition Ω (mutually exclusive, cover all outcomes), then:

P(A) = Σᵢ P(A | Bᵢ) · P(Bᵢ)

Example: A factory has 2 machines. Machine 1 produces 60% of items (2% defective). Machine 2 produces 40% (5% defective). P(defective) = 0.6×0.02 + 0.4×0.05 = 0.032

4. Bayes' Theorem

P(B | A) = [P(A | B) · P(B)] / P(A)

With partition {Bᵢ}:

P(Bⱼ | A) = P(A | Bⱼ)·P(Bⱼ) / Σᵢ P(A | Bᵢ)·P(Bᵢ)

Why it matters for AI/ML: Bayes' theorem is the foundation of Naive Bayes classifiers, Bayesian inference, and posterior updating in LLMs.

Medical test example: Disease prevalence = 1%. Test sensitivity = 99%, specificity = 95%.
P(D|+) = (0.99 × 0.01) / (0.99×0.01 + 0.05×0.99) ≈ 16.7%
Lesson: A positive test doesn't mean you're sick — prior probability matters hugely.

5. Independence of Events

A and B are independent if knowing B doesn't change P(A):

P(A ∩ B) = P(A) · P(B)  ⟺  P(A|B) = P(A)

Events A₁, A₂, …, Aₙ are mutually independent if for every subset:

P(Aᵢ₁ ∩ Aᵢ₂ ∩ … ∩ Aᵢₖ) = P(Aᵢ₁)·P(Aᵢ₂)·…·P(Aᵢₖ)
Exam trap: Mutually exclusive ≠ independent. If P(A)>0, P(B)>0 and A∩B=∅, they are dependent!

6. Exam Checklist

  • Compute P(A|B) from given tables or Venn diagrams
  • Apply total probability to find P(A)
  • Apply Bayes' theorem to reverse conditioning
  • Check independence using P(A∩B) = P(A)P(B)
  • Tree diagrams for sequential problems
