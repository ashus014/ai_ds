Foundations of Computer Systems

Semester 1 · Core Course · Online

Course Credit
L-T-P-C: 3-0-2-4
Learning Mode
Online
Assessment
Quiz / Assignment / ESE

Learning Objectives

The objective of the course is to provide a conceptual and theoretical understanding of computer architecture and operating systems.

Course Description

Foundations of computer systems is a review of two fundamental subjects of computer science viz., computer architecture and operating systems.

Course Outline

# Topic (from syllabus)
1Computer architecture: Performance measures, Memory Location and Operations, Addressing Modes, Instruction Set
2A Simple Machine, Instruction Mnemonics and Syntax, Machine Language & Assembly Language Program with examples
3Processing Unit Design: Registers, Datapath, CPU instruction cycle, Instructions and Micro-operations, Interrupt handling
4Control Unit Design: Control signals, Hardwired Control unit, Microprogram Control unit
5Pipelining and parallel processing, Pipeline performance, pipeline stall, methods to reduce stall; RISC and CISC
6I/O Transfer techniques; Memory organization: hierarchical memory, cache memories, virtual memory
7Operating systems: Process states, PCB, Fork, exec system call, Threads, Process scheduling
8Concurrent processes, Monitors, Process Synchronization, Producer Consumer Problem, Critical section, semaphore
9Deadlock, Resource Allocation Graph, Deadlock prevention, Deadlock Avoidance: Banker's Algorithm and Safety Algorithm
10Memory management techniques, Allocation techniques, Paging, Page Replacement Algorithms
11Lab Component: Implementation of above topics

Learning Outcomes

This course will revisit two fundamental subjects of computer science viz., computer architecture and operating systems, thereby enabling the students to pursue more advanced problems in computer science based on these topics.

Suggested Readings

  • A. Silberschatz, P. B. Galvin and G. Gagne, Operating System Concepts, 7th Ed, John Wiley and Sons, 2004.
  • M. Singhal and N. Shivratri, Advanced Concepts in Operating Systems, McGraw Hill, 1994.
  • David A. Patterson and John L. Hennessy, Computer Organisation and Design: The Hardware/Software Interface, Morgan Kaufmann, 1994.
