Access on a binary heap is peek min/max (root). Search is an arbitrary-element scan. Insertion / deletion of the root are heapify up/down. Build heap is listed in the section below.

Binary Heap (Min Heap / Max Heap)

Operation Binary Heap
Access (min/max) O(1)
Search O(n)
Insertion O(log n)
Deletion (root) O(log n)
Build Heap O(n)
A heap is usually listed as Binary Heap (Min Heap / Max Heap). Peeking the root is constant time. Floyd’s heapify builds the heap in linear time, which is better than n successive inserts (O(n log n)).
