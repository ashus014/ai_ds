322. Coin Change

Blind 75 #55 — Take/skip each coin (reuse allowed on take). Return min coins, or -1 if impossible. Recursion or memo.

Blind 75 / 1-D DP

Hint

Take/skip: take coin[idx] (reuse idx) or skip to idx+1. amount==0 → 0; invalid → MAX. Return min, else -1. Recurse or memo t[idx][amount].

Answers

Simple recursion

At each coin: take it (stay at idx) or skip it. Invalid paths return Integer.MAX_VALUE; map that to -1.

Solution.java — recursion 
class Solution {
    public int coinChange(int[] coins, int amount) {
        int result = solve(coins, 0, amount);
        return result == Integer.MAX_VALUE ? -1 : result;
    }

    private int solve(int[] coins, int idx, int amount) {
        // Base cases
        if (amount == 0) {
            return 0; // Successfully made the amount
        }

        if (idx >= coins.length || amount < 0) {
            return Integer.MAX_VALUE; // Invalid path
        }

        // For the current coin at index 'idx', we have two choices:

        // 1. TAKE the current coin
        int take = Integer.MAX_VALUE;
        if (amount >= coins[idx]) {
            int takeResult = solve(coins, idx, amount - coins[idx]);
            if (takeResult != Integer.MAX_VALUE) {
                take = 1 + takeResult;
            }
        }

        // 2. NOT TAKE the current coin (move to next coin)
        int notTake = solve(coins, idx + 1, amount);

        // Return the minimum number of coins needed
        return Math.min(take, notTake);
    }
}

✅ Memoisation

Same take/skip, cached in t[idx][amount] so each state is solved once.

Solution.java — memoisation 
import java.util.Arrays;

class Solution {
    int[][] t;

    public int coinChange(int[] coins, int amount) {
        int n = coins.length;

        t = new int[n][amount + 1];
        for (int[] row : t) Arrays.fill(row, -1);

        int result = solve(coins, 0, amount);
        return result == Integer.MAX_VALUE ? -1 : result;
    }

    private int solve(int[] coins, int idx, int amount) {
        // Base cases
        if (amount == 0) {
            return 0;
        }

        if (idx >= coins.length || amount < 0) {
            return Integer.MAX_VALUE;
        }

        // 🔥 memo check
        if (t[idx][amount] != -1) {
            return t[idx][amount];
        }

        // TAKE: use current coin
        int take = Integer.MAX_VALUE;
        if (amount >= coins[idx]) {
            int takeResult = solve(coins, idx, amount - coins[idx]);
            if (takeResult != Integer.MAX_VALUE) {
                take = 1 + takeResult;
            }
        }

        // NOT TAKE: skip current coin
        int notTake = solve(coins, idx + 1, amount);

        // store + return
        return t[idx][amount] = Math.min(take, notTake);
    }
}
