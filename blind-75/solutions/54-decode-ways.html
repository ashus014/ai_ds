91. Decode Ways

Blind 75 #54 — At index i: take 1 digit (if not '0') and/or take 2 digits if they form 10–26. Recursion or memo.

Blind 75 / 1-D DP

Hint

DFS from i: '0' → 0; end → 1; take 1 char + take 2 if 10–26. Recurse or memo t[i].

Answers

Simple recursion

From index i, take one digit (unless '0') and optionally two digits if they form 10–26. Sum the ways.

Solution.java — recursion 
// Simple recursion

class Solution {

    public int numDecodings(String s) {
        int n = s.length();
        return solve(0, s, n);
    }

    private int solve(int i, String s, int n) {


        if(i == n)
            return 1; // one valid split done

        if(s.charAt(i) == '0')
            return 0; // not possible to split

        int only_ith_char = solve(i + 1, s, n);
        int ith_plus_1_char = 0;

        if(i + 1 < n) {
            if(s.charAt(i) == '1' || (s.charAt(i) == '2' && s.charAt(i + 1) <= '6'))
                ith_plus_1_char = solve(i + 2, s, n);
        }

        return only_ith_char + ith_plus_1_char;
    }
}

✅ Memoisation

Same splits, cached in t[i] so each index is solved once.

Solution.java — memoisation 
class Solution {

    int[] t = new int[101];

    public int numDecodings(String s) {
        Arrays.fill(t, -1);
        int n = s.length();
        return solve(0, s, n);
    }

    private int solve(int i, String s, int n) {


        if(i == n)
            return t[i] = 1; // one valid split done

        if(s.charAt(i) == '0')
            return t[i] = 0; // not possible to split

        if (t[i] != -1)
            return t[i];

        int only_ith_char = solve(i + 1, s, n);
        int ith_plus_1_char = 0;

        if(i + 1 < n) {
            if(s.charAt(i) == '1' || (s.charAt(i) == '2' && s.charAt(i + 1) <= '6'))
                ith_plus_1_char = solve(i + 2, s, n);
        }

        return t[i] = only_ith_char + ith_plus_1_char;
    }
}
