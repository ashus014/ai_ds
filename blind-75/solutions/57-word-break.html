139. Word Break

Blind 75 #57 — From index idx, try every prefix in the dict; if it matches, recurse on the rest. Recursion or memo.

Blind 75 / 1-D DP

Hint

Put dict in a HashSet. From idx, try every substring s[idx..i); if in dict, recurse on i. idx==n → true. Memo t[idx].

Answers

Simple recursion

From idx, try every cut. If the prefix is in the dict and the rest can be segmented, return true.

Solution.java — recursion 
class Solution {

    Set<String> dict = new HashSet<>();

    public boolean wordBreak(String s, List<String> wordDict) {
        dict.addAll(wordDict);
        return solve(0, s);
    }

    private boolean solve(int idx, String s) {

        // 🎯 base case
        if (idx == s.length()) {
            return true;
        }

        // try all possible cuts
        for (int i = idx + 1; i <= s.length(); i++) {

            String temp = s.substring(idx, i);

            if (dict.contains(temp) && solve(i, s)) {
                return true;
            }
        }

        return false;
    }
}

✅ Memoisation

Same cuts, cached in t[idx] (-1 / 0 / 1) so each start index is solved once.

Solution.java — memoisation 
class Solution {

    Set<String> dict = new HashSet<>();
    int[] t; // -1 = not computed, 0 = false, 1 = true

    public boolean wordBreak(String s, List<String> wordDict) {
        dict.addAll(wordDict);
        t = new int[s.length()];
        Arrays.fill(t, -1);
        return solve(0, s);
    }

    private boolean solve(int idx, String s) {

        // 🎯 base case
        if (idx == s.length()) {
            return true;
        }

        if (t[idx] != -1) {
            return t[idx] == 1;
        }

        // try all possible cuts
        for (int i = idx + 1; i <= s.length(); i++) {

            String temp = s.substring(idx, i);

            if (dict.contains(temp) && solve(i, s)) {
                t[idx] = 1;
                return true;
            }
        }

        t[idx] = 0;
        return false;
    }
}
