647. Palindromic Substrings

Blind 75 #53 — Count every palindromic [i, j]: ends match and inner is palindrome. Recursion or memo.

Blind 75 / 1-D DP

Hint

Same palindrome check as LC 5: count all i≤j where s[i]==s[j] and inner is palindrome. Recurse or memo. i≥j → palindrome.

Answers

Simple recursion

For every [i, j], recurse inward if the ends match. Increment count when the substring is a palindrome.

Solution.java — recursion 
// Simple recursion

class Solution {

    public int countSubstrings(String s) {
        int n = s.length();
        int count = 0;

        for(int i = 0; i < n; i++) {
            for(int j = i; j < n; j++) {
                if(solve(s, i, j)) {
                    count++;
                }
            }
        }

        return count;
    }

    boolean solve(String s, int i, int j) {
        if(i >= j) {
            return true;
        }

        if(s.charAt(i) == s.charAt(j)) {
            return solve(s, i + 1, j - 1);
        }

        return false;
    }
}

✅ Memoisation

Same check, cached in t[i][j] so each pair is solved once.

Solution.java — memoisation 
// Memoisation

class Solution {

    public int countSubstrings(String s) {
        int [][]t = new int[1001][1001];
        for(int i = 0; i < 1001; i++) {
            Arrays.fill(t[i], -1);
        }

        int n = s.length();
        int count = 0;

        for(int i = 0; i < n; i++) {
            for(int j = i; j < n; j++) {
                if(solve(s, i, j, t) == 1) {
                    count++;
                }
            }
        }

        return count;
    }

    private int solve(String s, int i, int j, int [][]t) {
        if(i >= j) {
            return 1;
        }

        if(t[i][j] != -1) {
            return t[i][j];
        }

        if(s.charAt(i) == s.charAt(j)) {
            return t[i][j] = solve(s, i + 1, j - 1, t);
        }

        return t[i][j] = 0;
    }
}
